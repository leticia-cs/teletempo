# Teletempo

Sistema de ponto para teletrabalho.

## Funcionalidades

- Hora de entrada, saída e almoço
- Cronômetro para almoço fixo (1h)
- Temporizador para almoço livre (sem limite)
- Botão exportar
- Notificações in-app quando o registro é concluído

## Como compilar

### Para computador

1. Baixe o projeto do GitHub (.zip)
2. Vá em algum diretório do seu computador e descompacte em um novo diretório (ex: ./Documentos/teletempo)
3. Dentro do diretório criado (ex: "teletempo"), abra uma janela do terminal/console.
4. Para criar o executável, digite o seguinte comando:

`pyinstaller app.spec`

--> Serve para Linux, Windows, Mac

5. Vá para o novo diretório criado automaticamente (ex: "dist").
6. Dê clique duplo para executar. Se preferir no terminal, só rodar o seguinte:

`./teletempo`

7. Aproveite!

<br>END

### Para telefone

1. Baixe o projeto do GitHub (.zip)
2. Vá em algum diretório do seu computador e descompacte em um novo diretório (ex: ./Documentos/teletempo)
3. Dentro do diretório criado (ex: "teletempo"), abra uma janela do terminal/console.
4. Rode o projeto na rede local

`flask run`

5. O terminal retornará um endereço de navegador. Copie-o.

`http://127.0.0.1:5000`

6. Vá para o seu telefone e abra uma aba de navegador
7. Digite o endereço copiado anteriormente
8. Aproveite!
